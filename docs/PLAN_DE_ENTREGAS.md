# Plan incremental — Subasta FC

1. **Etapa 1: Arquitectura y lobby.** Estructura modular, diseño UI, crear/unirse, 5 cupos, estados y pruebas.
2. **Etapa 2: Motor de subastas.** Rondas, reloj autoritativo, pujas concurrentes, extensión y adjudicación.
3. **Etapa 3: Plantilla y resultados.** Formación, puntuación reproducible y clasificación.
4. **Etapa 4: Persistencia y seguridad.** Firebase Auth, PostgreSQL, Redis, reconexión robusta y pruebas de carga.
5. **Etapa 5: Android.** Configuración de red, iconos, splash, build APK/AAB, firma y pruebas en dispositivos.
6. **Etapa 6: Expansión.** Mercado, misiones, tienda, rankings, perfil, minijuego y progresión.

**No avanzar de etapa sin comprobar sus criterios de aceptación.**
