# Subasta FC V6 — mejoras visuales

- Silueta individual del futbolista, ampliada, sin superposición de títulos.
- Imagen real del jugador en la revelación, con respaldo a la carta.
- Campo 4-3-3 rediseñado con franjas, líneas, área y posiciones LI / DFC / DFC / LD.
- Los diez defensas centrales suministrados solo se asignan a DFC; sobrantes fuera del once.
- Cartas con mayor tamaño y proporción original (object-fit: contain).
- Conserva backend y WebSockets de V5.

**Limitación:** faltan laterales reales, porteros, mediocampistas y delanteros. La alineación 4-3-3 completa sigue siendo provisional. La interfaz no incluye aún gestión manual de reservas.
